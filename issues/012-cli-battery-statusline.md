# Батарейки контекста и лимитов в Codex CLI

Статус: отложено по решению владельца 2026-11-06.

В CLI 0.166.0 штатная строка показывает текстовые context/weekly fields. Владелец хочет видеть заполненные шкалы, где заполнение означает оставшийся ресурс, и точные значения рядом.

- [ ] Проверить поддержку custom renderer в выбранной версии CLI перед разработкой.
- [ ] Если понадобится свой build: выбрать способ сопровождения патча и обновления официального клиента.
- [ ] Подготовить варианты батареек для контекста, пятичасового и недельного лимитов.
- [ ] Показывать точный остаток контекста в токенах и процентах, если клиент предоставляет эти данные.
- [ ] Показывать время сброса лимита, когда оно доступно.
- [ ] Отсутствующие данные отображать как неизвестные, не как 0 или 100 процентов.
- [ ] Проверить узкий терминал, светлую/тёмную тему, Unicode, resize и доступность без цвета.
- [ ] Добавить обратимую установку, проверку версии и возврат к официальному CLI.
- [ ] Не менять авторизацию, правила доступа, протокол модели и поведение инструментов ради оформления.

Штатный statusline остаётся рабочим до выполнения этой задачи. Исходный код CLI можно изменять, но наличие upstream extension point и стоимость поддержки ещё предстоит проверить.
