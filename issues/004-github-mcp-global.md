# #004 — GitHub MCP глобально вместо `gh` через Bash

**Статус:** открыто
**Создано:** 2026-10-12

## Проблема
GitHub MCP настроен только в проекте `romantic-landing`. В остальных проектах Claude работает с GitHub через `gh` в Bash.

## Решение
Подключить GitHub MCP на user-уровне. Токен — fine-grained PAT с минимальными правами, хранить вне репозитория харнесса (keychain или env).

## Открытые вопросы
- Оставлять ли `gh` как запасной путь. Скиллы `issue-start` и `issue-done` сейчас, скорее всего, завязаны на `gh` — проверить и перевести.
- Количество инструментов MCP: GitHub MCP добавляет много инструментов в контекст. Проверить, можно ли ограничить toolsets.

## Критерии готовности
- [ ] GitHub MCP доступен в любом проекте.
- [ ] `issue-start` / `issue-done` работают через него.
