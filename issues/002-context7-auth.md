# #002 — context7 постоянно слетает аутентификация

**Статус:** открыто
**Создано:** 2026-10-12

## Проблема
Плагин `context7@claude-plugins-official` подключается к MCP через OAuth, и авторизация регулярно слетает. Каждый раз приходится логиниться заново (`mcp__plugin_context7_context7__authenticate`).

## Варианты
- Подключить context7 как обычный MCP-сервер с API-ключом в заголовке (`CONTEXT7_API_KEY`) вместо OAuth-плагина. Ключ хранить вне репозитория харнесса.
- Локальный вариант через `npx @upstash/context7-mcp`.

## Критерии готовности
- [ ] Неделю работы без повторной авторизации.
- [ ] Конфиг MCP лежит в репозитории харнесса, секрет — нет.
