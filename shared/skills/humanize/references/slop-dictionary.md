# Словарь слопа

Читай этот файл, когда правишь длинный текст: сгруппировано по типам, так ловится быстрее, чем перечитыванием подряд.

Правая колонка — не механическая замена. Слово из левой колонки почти всегда значит, что автор не назвал факт; замена — это указание, **какой факт надо назвать**. Если факта нет и взять его негде, фразу вырезают, а не переписывают синонимом.

## Оценки без меры

Прилагательное, которое нельзя опровергнуть, ничего не сообщает. Спрашивай «по сравнению с чем и в каких единицах» — ответ и есть текст, который надо написать.

| Слово | Что назвать вместо |
|---|---|
| робастный, надёжный | какие входные выдерживает, где падал раньше |
| гибкий, расширяемый | что можно добавить, не трогая существующий код, и на каком примере это проверено |
| мощный, продвинутый | что умеет такого, чего не умеет очевидная альтернатива |
| эффективный, оптимальный | число: время, память, количество запросов |
| элегантный, чистый, красивый | сколько строк, сколько ветвлений, сколько мест правки при изменении |
| современный, актуальный | версия, дата, что именно устарело в предыдущем |
| удобный, интуитивный | сколько кликов, что теперь не надо помнить |
| масштабируемый | до какой нагрузки проверено и чем |
| производительный | замер: было столько, стало столько |
| комплексный, всеобъемлющий | перечислить, что входит; обычно выясняется, что входит два пункта |
| качественный, грамотный | вырезать, это оценка себя |
| безопасный | от какой конкретно атаки защищает |
| простой, лёгкий | во сколько строк, сколько зависимостей |

## Отглагольные конструкции

Русский технический текст тонет в номинализациях. Глагол короче и всегда называет действующее лицо.

| Как пишут | Как сказать |
|---|---|
| осуществляет обработку | обрабатывает |
| производит валидацию | проверяет |
| выполняет инициализацию | поднимает, создаёт |
| реализует механизм преобразования | преобразует |
| обеспечивает возможность конфигурации | позволяет настроить, читает настройку из |
| происходит вызов метода | вызывает |
| является ответственным за | отвечает за, делает |
| представляет собой | это (чаще — вырезать вместе с половиной предложения) |
| имеет место быть | есть, происходит |
| осуществляется взаимодействие с | ходит в, дёргает |
| выступает в качестве | работает как |
| производится отправка запроса | отправляет запрос |

Отдельный признак: цепочка родительных падежей. «Настройка процесса обработки конфигурации подключения клиента» — четыре подряд, читатель теряет нить на третьем. Разбивать на глаголы: «клиент читает конфиг при подключении».

## Прокладки и вводные

Вырезаются целиком. Проверка: удали и перечитай — если смысл не изменился, это была прокладка.

- важно отметить, что
- стоит отметить / стоит учитывать / следует понимать
- по сути / фактически / собственно говоря
- как известно / как правило / зачастую
- в рамках данного подхода / в контексте данной задачи
- необходимо понимать, что
- давайте разберём / давайте посмотрим (в письменном тексте — разгон перед делом)
- на самом деле (почти всегда лишнее; если правда есть противопоставление — назвать обе стороны прямо)
- в целом / в общем и целом
- что касается X, то
- нельзя не отметить
- отдельно хочется сказать

## Метафоры вместо механизма

Метафора допустима, если сразу за ней идёт механизм. Одна метафора без механизма — это отказ объяснять.

| Метафора | Что за ней должно стоять |
|---|---|
| оркестрирует | что за чем вызывается, в каком порядке, кто ждёт кого |
| под капотом | конкретный вызов или файл |
| из коробки | какой дефолт и где он задан |
| прокидывает | через какой проп, событие, контекст |
| единый источник правды | какой именно файл или стор, и что происходит при расхождении |
| магия / автоматически | какой код это делает |
| бесшовно, прозрачно для пользователя | что пользователь увидит и чего не увидит |
| шина событий, пайплайн | список шагов |
| завязан на / тесно связан | какой импорт, какое поле, что сломается при удалении |
| живёт своей жизнью | что конкретно расходится с ожиданием |

## Хеджирование

Хедж размывает ответственность за утверждение. Оговорка её очерчивает. Первое вырезать, второе оставить.

Хедж (вырезать или заменить фактом):
- может потенциально приводить к проблемам
- в некоторых случаях возможны сложности
- не исключено, что
- теоретически может не работать
- есть вероятность возникновения

Оговорка (оставить, это информация об охвате проверки):
- проверял только на роли `manager`
- воспроизводится на медленной сети, на быстрой не поймал
- не проверял, смотрел только по коду
- на данных больше 1000 строк не гонял

Если знаешь условие — назови его: не «может падать», а «падает, когда массив пустой». Если не знаешь — скажи, что не знаешь; это честнее и полезнее, чем «потенциально».

## Эскалация

Наречие силы не добавляет утверждению веса, оно добавляет шума. Факт после его удаления тот же.

критично важно · фундаментально · кардинально · значительно · существенно · радикально · крайне · чрезвычайно · абсолютно · полностью (когда не про полноту, а для нажима)

Исключение: когда степень измерена. «Значительно быстрее» — шум. «В пятнадцать раз быстрее» — факт.

## Кальки

Не всякий англицизм плох: часть — общепринятые в цехе термины, и русская замена читалась бы хуже. Плохи те, что заменяют объяснение.

| Калька | Замена |
|---|---|
| леверажить, заэнфорсить, зааффектить | использовать; обеспечить/проверять; повлиять |
| поверхность API | что торчит наружу: список методов, пропсов, событий |
| комплексное решение | что входит |
| в терминах X | вырезать |
| нативно поддерживается | поддерживается; кем и с какой версии |
| консистентность (в бытовом смысле) | согласованность, одинаковость |
| имплементация | реализация (или просто «код») |
| перформанс | скорость, время отрисовки, число запросов |
| юзкейс | случай, сценарий |
| дизайн решения (в значении «замысел») | устройство, схема |

Остаются как есть, потому что сокращают объяснение: race condition, идемпотентность, реактивность, дебаунс, мемоизация, тайпчек, линтер, деплой, `snake_case`, guard, стор, экшен.

## Английский слоп

Тот же список для англоязычных текстов и код-ревью.

- it's worth noting that · it should be noted · it's important to understand
- robust · seamless · powerful · elegant · comprehensive · cutting-edge
- leverage (как глагол) · utilize (вместо use) · facilitate
- best practices (без указания чьих и почему)
- this is not just X — it's Y
- at the end of the day · when it comes to · in terms of
- ensures optimal performance · enhances maintainability
- delve into · dive deep · unpack

## Конструкции-каркасы

Синтаксические фигуры, которые выглядят как мысль, но держат пустоту.

**Антитеза без содержания.** «Это не просто рефакторинг — это смена подхода.» Обе половины ничего не называют. Написать, что изменилось.

**Тройка ради ритма.** «Чисто, быстро и надёжно.» Третий элемент дописан для благозвучия и обычно неправда. Оставить то, что проверено.

**Каталог вместо диагноза.** «Есть вопросы к производительности, читаемости и поддерживаемости.» Три ярлыка вместо одной находки. Найти самую дорогую проблему, дать ей адрес, остальное — либо так же конкретно, либо никак.

**Круговое определение.** «Стор отвечает за управление состоянием стора.» Сказать, какие данные лежат и кто их пишет.

**Обещание вместо результата.** «Это позволит в дальнейшем упростить поддержку.» Проверить нельзя никогда. Заменить на то, что уже случилось: «правка цены теперь в одном файле вместо четырёх».

**Пересказ очевидного из имени.** «Функция `getUserById` получает пользователя по идентификатору.» Такое предложение можно удалить целиком: имя уже сказало. Писать надо то, чего в имени нет — что вернётся, если не нашли, и ходит ли она в сеть.
