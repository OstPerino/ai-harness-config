# ChatIndex — карта чатов Telegram

Справочник «человеческое имя → chat_id / алиасы / топики». Skill резолвит сюда
имена, чтобы не вспоминать числовые ID. Заполняй по мере использования
(субагент `telegram-manager` может предлагать новые записи из `list_chats`).

## Личные чаты (DM)

| Алиасы (как зовёшь)      | chat_id      | Заметка                  |
|--------------------------|--------------|--------------------------|
| Андрей, коллега, Andrey  | `<заполни>`  | автор исходной спеки      |
| _пример_                 | `123456789`  |                          |

## Группы / каналы

| Алиасы            | chat_id        | Заметка            |
|-------------------|----------------|--------------------|
| _пример: команда_ | `-1001234567`  | супергруппа         |

## Топики форумов

| Чат (алиас) | Топик       | topic_id |
|-------------|-------------|----------|
| _команда_   | _general_   | `1`      |
| _команда_   | _релизы_    | `<id>`   |

---
Как узнать chat_id: попроси «telegram: покажи последние чаты» — субагент вернёт
список с id; впиши нужные сюда.
